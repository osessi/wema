Boutons

Un bouton déclenche une action. Le jaune est rare : une seule action phare par zone ; le biseauté est réservé à l'action principale d'un écran.

  • ghostDans une barre d'outils

13 · Illustrations13 · Illustrations

Illustrations

Une figure Hairline accompagne un moment sans contenu ou un moment clé (vide, bienvenue, erreur), jamais un écran de travail. Elle est décorative : le texte à côté dit tout. Elle répond au pointeur et devient une image fixe si l'on réduit les animations.

  • Aucun devoirdrawer

    Un classeur : le tiroir s'ouvre sur du vide.

  • Aucun messagerouter

    Un routeur dont les antennes cherchent le signal.

  • Aucune classelockers

    Une rangée de casiers d'école.

  • Aucun exercicebasket
